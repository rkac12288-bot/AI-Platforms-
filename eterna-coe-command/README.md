# Eterna CoE Command

A command platform for running a **GenAI Centre of Excellence** across a large Brazilian holding with 6 divisions and 14 business functions. It gives the CoE Director and every C-level role one view of adoption, ROI, EBITDA impact, delivery health and governance.

> "Grupo Solvane S.A." and its divisions are fictional. All people, figures and pilots are illustrative.

## The problem it solves

In a large holding, GenAI spreads faster than anyone can govern it: each function buys its own tools, pilots never scale, data ends up in public chatbots and nobody can show the board what it is worth. Eterna CoE Command runs a **hub-and-spoke** model — the hub owns platform, security and standards; each function owns its use cases and results — and tracks everything against an EBITDA mandate of 200–300bps.

## Modules

| Area | Modules |
|---|---|
| **Command** | CoE Command Center (board summary, critical risks, KPIs, 90-day pilots, OKRs) · Business Functions · Capability Radar · Scenario Planner |
| **Operations** | Resource Optimizer · Budget & ROI Tracker · Delivery Health |
| **Intelligence** | Enterprise Intelligence · Decision Engine · Governance Board |
| **System** | Initiative Intake · CoE Playbooks · CoE Policy Settings |

**Role views** switch the whole platform between CoE Director, CEO, CDO, CFO, CTO and CDA perspectives.

## Highlights

- Function heat map of adoption against a 65% target, with champions and bonus-at-risk tracking
- ROI and EBITDA contribution per function and per division
- Concurrent 90-day pilot tracker across divisions
- Shadow-IT detection and pay-per-use chargeback
- Regulatory readiness for LGPD, BACEN and the Brazilian AI Bill
- CEO portfolio report

## Tech

- Single self-contained HTML file, vanilla JavaScript
- Chart.js from CDN
- No backend: all data and calculations live in the page

## Presentation

`presentation.html` tells the story of the platform in 9 slides: the problem, the hidden cost, how the platform works, the key insight and the results. Use the arrow keys to move between slides.

## Run it

Open `index.html` in any modern browser.
