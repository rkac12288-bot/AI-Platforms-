## About this work

I build AI platforms that turn dense, expert-only data into something a decision-maker can read and act on. A few principles run through everything here:

- **Storytelling over data-dumps** — a number isn't useful until someone knows what to do about it.
- **Graceful degradation** — AI should enhance a product, never be a single point of failure.
- **Intellectual honesty** — demo data, illustrative integrations, and simulations are always labeled as such.
- **Zero-friction delivery** — self-contained builds that open and run anywhere.
